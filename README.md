# Robot-6-Email-Customer-Support-Agentic-AI
UiPath Eugene is an AI agent that answers technical UiPath questions by email in seconds, searching and scraping the UiPath Forum, and is triggered by a Gmail webhook. If unsure or asked, it forwards the email to a human and tells the student to expect an answer within 24 hours, using UiPath Maestro and an OpenAI-powered agent.
